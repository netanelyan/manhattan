MANHATTAN BRAND ASSETS

COLORS
  Light  #F2F2F0
  Dark   #1B1D1F
  The logo is one color on one background: light on dark, or dark on light.

FONTS
  Logo           Chakra Petch Bold        https://fonts.google.com/specimen/Chakra+Petch
  Secondary logo IBM Plex Mono SemiBold   https://fonts.google.com/specimen/IBM+Plex+Mono
  All text in the logo files is already converted to shapes, so no font install is needed.

FOLDERS
  primary/    Main logo (chip + MANHATTAN), chip mark only, wordmark only
  secondary/  Part-marking logo: full color, plus flat one-color versions for print
  icon/       App icon, favicon.ico, Apple touch icon, square avatar for social profiles

FILE NAMES
  -white  light logo, for dark backgrounds
  -black  dark logo, for light backgrounds
  svg/    vector, for web and design tools
  pdf/    vector, for print (shirts, stickers)
  png/    transparent background, high resolution

PRINT SIZE
  Keep the main logo at least 75 mm wide so the thin chip wires hold up.
  For anything smaller, use the chip mark alone, at least 12 mm wide.
